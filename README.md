# Rock Paper Scissors (JavaScript)
A simple Rock-Paper-Scissors game in JavaScript, created while following 「TheOdinProject」 Foundations Course. It is currently playable in the Browser Console.

## Features
- Able to play against the computer with randomized choices
- Keeps track of wins and losses

## Demonstrated Skills
- Basic JavaScript Syntax
    - Functions
    - Conditionals
    - Loops
- Problem-Solving and Debugging

## How to Run
1. Clone the repo
2. Open index.html in the browser
3. Play using the console
